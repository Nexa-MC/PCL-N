# NexaCL Firefly Alpha 6 界面预览

本轮改动的实际界面预览：30 张 PNG、10 段单次播放 GIF，包含亮暗主题的 Splash、主窗口、资源列表及详情、外观设置。资源记录和失败/重试响应使用已标注的受控演示数据。

- [下载完整预览包](https://github.com/Nexa-MC/PCL-N/raw/refs/heads/refactor/xsr/docs/previews/firefly-alpha.6/NexaCL-Firefly-previews.zip)
- [下载单文件离线预览](https://github.com/Nexa-MC/PCL-N/raw/refs/heads/refactor/xsr/docs/previews/firefly-alpha.6/NexaCL-Firefly-previews.html)

解压 ZIP 后用浏览器打开 `index.html`，可切换主题、查看全部页面、放大图片、播放与重播 GIF。HTML 包含全部图片，无需联网；ZIP 同时包含原始尺寸的 PNG/GIF、素材清单及采集验证记录。

预览脚本与复用命令见 [eng/previews](../../../eng/previews/README.md)。
