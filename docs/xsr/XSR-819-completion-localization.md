首次收口添加 194 个固定或限定模板条目；第二轮补齐身份、文件工作区、离线就绪、
网络诊断、CLI、命令面板及原生操作等 135 个条目。第三轮补齐 20 个后续固定文案
与设置目录的间接标签；第四轮覆盖世界健康检查等 11 条新增文案。
第五轮补齐 Java 诊断、世界快照、截图时间线与运行诊断等 81 条。
最终 freeze 扫描补齐版本列表的 1 条不可用实例提示。
最终实例运行诊断补齐状态、资源采样与系统事件关联等 35 条。
最后持久实例历史补齐运行/崩溃记录状态、退出时间与读取失败等 13 条。
运行 Trace 工作区补齐捕获、环容量、丢弃状态与标题等 10 条。
最终系统协议状态与 AI 偏好准入反馈补齐 10 条。
最后源冻结补齐高级启动事实、实例身份与操作历史、硬件建议、恢复时间线、
手动 Java 下载、高级工作区和网络状态等 179 条。
Java 库存另补启动器托管/外部运行时 2 条。
原生 graphics 能力与准入说明另补 5 条。
Java 选择与强制兼容性说明另补 5 条。
最终能力目录澄清另补 2 条。
最后导航缺失回调和无可编辑分类说明另补 6 条；移除已经没有生产消费者的
6 条“尚未迁移”占位文案。Java 选择策略未完成读取的真实状态另补 1 条。
实例选择消失后的真实提示另补 1 条。
原始设置本机打开的凭据提示另补 1 条。
内容 SHA-256/修改状态工作区另补 17 条。
最终全量扫描再补齐 241 条历史及最后新增文案，覆盖原生文件选择、服务器与内容依赖、
恢复摘要、Hooks 命令编号、GPU 选择、内容信任事实和本地设置打开失败反馈。
以 HEAD 的 2125 条为基准，本轮共新增 970 条、移除 6 条，净增 964 条，最终目录为
3089 条，其中普通条目 2899 条、限定模板 190 条。Desktop/backend 生产 C# 的固定中文
字符串及中文插值形状、Desktop PXML 的可见属性、SettingsCatalog 的 label/section
全量扫描均无缺失；排除四个内部实体/标记字符串以及动态用户/提供方正文。

模板只翻译固定文本，保留捕获的用户名称、路径、账户、时间和错误值；不递归翻译
捕获参数。Sidecar 文字、AI 回复、原始诊断正文和其他提供方内容保持 literal。
启动 Splash 由原生会话的本机 localizer 回调消费，固定阶段与取消按钮也覆盖。
备份行仅先翻译“个文件”再拼接保留的用户标签和日期。
文件标题先翻译可编辑/只读后缀后拼接 literal 路径。原生通知的标题/正文在 UI
dispatcher 捕获当前翻译；Linux action flag 保留协议部分，仅翻译“打开 NexaCL”。
Sidecar 图片可访问标签与输入说明保持 literal，避免动态插件文字被目录碰巧匹配。
不可用设置的辅助名称分别翻译固定设置标签和原因后组合，避免组合文案漏翻。
服务器人数固定单位、恢复摘要的有限 Kind/Category 和 AI 确认的有限 scope 先翻译，
然后与数字或 literal 正文组合；捕获参数本身不会递归翻译。恢复摘要仅翻译生产方的
九种分类和五种更改类型，未知分类及路径保留原值。AI 预览和建议正文保留 literal，
确认模板在 UI dispatcher 上翻译后格式化，后台任务不访问 renderer。
Hooks 的命令编号先翻译普通格式键，再格式化编号；用户命令正文保持原值。
最后另核对多行 fallback 的真实消费边界：原字符串中用于拼接的首/尾换行不会出现在
拆分后的行中，因此补齐对应的有限行别名。原始诊断导出与 AI 确认都在 UI dispatcher
翻译普通格式键后拼接 literal 预览，并禁用对整个消息的再次翻译；超过模板匹配长度
上限的原文也不会影响固定标题的翻译。

现有 LocalizationTests 遍历全部目录条目检验英文/繁体消费及模板占位，同时覆盖
literal 参数及语言切换。最终静态 JSON 检查通过：无重复 JSON 对象键或源文本，
source/en/zh-Hant 均为非空字符串，全部格式编号一致；模板保留全部编号参数、
参数数量在 1–16 范围且无相邻不可区分参数。按真实目录顺序模拟所有条目的
英文/繁体消费，未发现模板遮蔽。完整 Desktop 与 NativeAOT 集成验证见
[XSR-820](XSR-820-completion-closure.md)。
