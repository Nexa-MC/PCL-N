# XSR-798 — Firefly 桌面集成与列表入场修复

本切片补齐托盘、默认开启的单实例模式、`nexacl://` 注册、右键菜单，并将默认版本
推进至 `2.0.0.alpha.6`，开发代号 Firefly。正式 Alpha 6 界面显示
`NexaCL Firefly Alpha 6`，下方显示 `v2.0.0.alpha.6`；其他构建仍使用实际版本身份。

## 架构锁

Desktop 在启动恢复和数据写入前取得用户级单实例租约；第二进程通过用户隔离的异步
命名管道转发激活请求，等待确认后退出。工作进程和验证入口不参与单实例或系统注册。
租约使用固定引导目录，不随用户迁移数据目录而变化。协议仅接受受支持的导航路由，
不执行来自 URI 的任意命令、文件或参数；请求、排队和等待时间均有上限。
关闭期间每次管道连接最多等待 250 毫秒，随后重新尝试租约；总等待预算仍为 5 秒。
主监听器退出后，连接等待不能阻止第二进程取得刚释放的租约。

协议关联在用户级注册，Windows 使用 HKCU，Linux 使用桌面文件与 MIME 关联，macOS
使用应用包 URL 类型和 Launch Services。不需要管理员权限；不可用或失败应显式报告。
默认启用托盘，默认关闭按钮仍退出；可设置关闭/最小化到托盘。无可用托盘时保留窗口，
没有托盘宿主时关闭到托盘退回普通最小化，窗口仍可从任务栏找回；Linux 宿主消失
后最多 15 秒自动恢复窗口。显式退出仍经过已有安装退出协调器，真正退出释放托盘、
监听器与实例租约。首次设置和更新的重启均在租约释放后启动新进程。

Services 只持有类型化设置。Desktop 将已提交的桌面策略传给原生后端；后端拥有系统
托盘、窗口和操作系统效果。右键菜单从 UI.Next 组件生成不可变场景信息，菜单选择发出
原有语义 intent，业务目标退休、禁用或页面离开后不能执行；全局菜单在模态弹窗期间
不能执行。文本菜单复用已有编辑和剪贴板
权限规则，密码字段不允许复制或剪切；右键不执行左键激活或拖动。

列表入场只由首次展示及实际导航/显式 transition key 变化触发。普通场景修订、滚动
裁剪后重新可见、状态刷新不重放入场；减少动态效果继续直接落至最终状态。

## 验证

2026-10-07（Asia/Shanghai），Debian 13 / .NET SDK 10.0.100 / linux-x64：

- Services 627 项、Desktop 200 项同时通过 CoreCLR 与真实 NativeAOT；桌面测试
  使用独立子进程验证转发、队列上限、退出期间接管和租约释放。
- UI.Next 100 项、Avalonia 后端 15 项、PXML 40 项通过；覆盖列表重复刷新和滚动
  返回、正常导航入场、退休菜单、密码剪贴板、模态保护、托盘关闭与显式退出。
- 70 个项目的架构检查、发布脚本 6 项测试、格式检查通过；521 实体干净重绘
  零分配性能门禁通过。
- 最终完整 Release 构建使用 `-warnaserror`，0 警告、0 错误。
- 正式 Alpha 6 NativeAOT 产物为 ELF，无主程序集 DLL；主壳验证输出 54 个语义
  节点，首次设置验证正常退出。真实 X11 窗口标题、用户级 MIME 关联、第二启动器
  `nexacl://settings` 转发和主窗口正常关闭均实测通过。
- 独立裁剪产物完成 `Optimizing assemblies for size`，主壳同为 54 个语义节点；
  主壳与首次设置探针均退出 0。所有发布均从恢复依赖开始，避免 AOT/裁剪缓存混用。

当前目录仍有 540 个位置：87 个原始 Available、453 个原始 NotImplemented；
值定义 50 个，其中 49 个已有消费者。历史清单中的计数保留其切片时点。
本次新增四个全局设置：单实例和托盘默认开启；关闭到托盘、最小化到托盘默认关闭。
单实例修改下次启动生效，三项托盘策略立即生效。

协议支持 `nexacl://` 激活现有页面，以及 `nexacl://launch`、`install`、`resources`、
`settings` 和对应 `nexacl://open/<route>`；不支持的路径、查询或认证参数被拒绝。
Linux 无托盘宿主的回退已覆盖；Windows/macOS 的实际系统托盘和 URL 回调仍需
在对应桌面平台验收，不能以 Linux 测试替代。

## 标题展示修订（2026-10-08）

主窗口及首次设置标题改为 `NexaCL`，标题栏不再附版本副标题。更新页和关于页
显示 `NexaCL Firefly v<实际版本>`。此前 Alpha 6 窗口标题实测记录属于修订前快照。

修订验证：完整 Release 构建 0 警告/0 错误，Desktop 200 项、PXML 40 项和格式检查通过。
