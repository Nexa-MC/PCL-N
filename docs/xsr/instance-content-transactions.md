# 版本内容移除与还原

Alpha.6 删除预览通过反向依赖索引展示直接及间接受影响的启用模组；别名与同文件内的
多个 Mod identity 一并传播，循环终止，停用模组不产生运行时依赖提示。该展示仍是
metadata 线索，不是新的 preflight Block。依赖缺失/未知继续保守退出，自动移除前置
仍只使用既有 hash/stamp 绑定的 orphan 计划并在事务内复验。

版本内容管理以完整实例目录和 Service 返回的页面标识定位文件，不接受 UI 指定任意目标目录。
移除操作先写持久记录，再将单个目录项原子移动至同一游戏目录的 `.nexa-content-trash`；
不递归删除存档或资源。启动器异常退出不会丢失已移走的内容。还原拒绝覆盖同名文件。
对共享游戏目录，任一使用者运行时拒绝写入；修改在根目录独占门控下执行。
列表与记录读取有数量及字节上限；原项大小/修改时间必须与用户看到的一致，链接拒绝操作。
此处不宣称抵御同账户恶意进程持续换链，也不提供永久清空回收站。
